# FlowTrace — honest current-state audit and launch roadmap

## The verdict in five sentences

The mechanism the README sells is real: `.build/debug/flowtrace now` returned "17 places · 11 agents · 8 servers" in 0.8s with zero permissions, the Quick Capture panel appears over what you're doing, knows the page, hands focus back, and never drops a note, and the "no network client" privacy claim survives a grep of the entire source tree. But the loop leaks at both joints — a note is written onto whatever recorder span happens to be open rather than where you pressed the key (`QuickCaptureView.swift:289-291,318-340`), and once written it can only be found by paging Today one day at a time — and the author's own database (1,181 ambient rows, 32 agent sessions, 4 notes ever, 0 project notes) is the honest measure of how much the current build invites the "why". Two privacy claims are false in code today (transcripts are read and imported before the consent screen is shown; raw prompts with live API keys sit unredacted in `scanCache`), which is exactly what a privacy-pitched launch will be tested on. The launch wrapper does not exist yet: no icon, no downloadable build, no screenshot, and a README/onboarding/CLI/menubar that each describe a different product with a different default shortcut. None of this is deep — every Tier 0 item is S or M — but shipping the current build to strangers would burn the one first impression a solo maker gets.

## What already works (keep, don't touch)

- **Snapshot-before-activate and focus hand-back.** `FrontmostSnapshot.capture()` runs before `NSApp.activate` (`Sources/FlowTraceApp/Capture/FrontmostSnapshot.swift:42-48`, `QuickCapturePanel.swift:77-101`) and focus returns to the previous app on dismiss (`QuickCapturePanel.swift:117-125`). The real debug.log shows every fire returning focus 5-7s later. The panel feels summoned, not opened (hidden title bar, floats over full-screen apps, `QuickCapturePanel.swift:24-36`).
- **Async tab enrichment with an honest denial state.** The panel appears instantly; a denied Automation permission is shown inline with an Allow… button (`QuickCaptureView.swift:95-117, 294-306`; `BrowserAccess.swift:6-11`).
- **"Your words are yours" enforced in the store.** Only annotated rows earn a timeline line (`Sources/FlowTraceCore/Activity/ActivityStore.swift:84-101`); prune never deletes a noted row (170-183); re-import never overwrites a note (206-231). 35 tests in `ActivityTests.swift` cover coalescing and resume — the best-tested code in the repo.
- **Tab notes and quick-capture notes are one table, keyed on URL** (`Live/LiveBrowser.swift:49-104`), so "the note outlives the tab" has real plumbing; it just lacks a surface.
- **Smart Capture Phase 1 is implemented as specified**: deterministic `CaptureSuggester` in Core, tested; second pass re-suggests when the tab resolves and stays silent once the user has typed (`QuickCaptureView.swift:273-283, 298-304`); suggestion text in `.yourWords`, hint in `.observed` (237-244).
- **Live discovery is cheap and grouped correctly.** pgrep 0.04s, batched lsof 0.02s (`LiveStateReader.swift:157-191`); grouping by repo root (`LiveProject.swift:64-98`) delivers the "agent + server in one place" insight; prompts are tail-read with widening, meta/sidechain filtered, and redacted before display (222-261, 68-77).
- **`flowtrace scan` is the best "where I stopped" rendering in the codebase** (`Sources/flowtrace/Scan.swift:91-126`) — session title, filenames, last commit, 3-prompt arc. `ResumeBrief` prose (`Brief/ResumeBrief.swift:84-133`) is well-judged for a model's context.
- **Privacy architecture.** No `URLSession`/`NWConnection`/`import Network` anywhere in `Sources/`; the only `socket()` is the loopback listener bound to `INADDR_LOOPBACK` (`Server/LocalServer.swift:84,95`); token-gated on every route but `/health`, CORS extension-origin only, 15 route tests. Subprocesses are hardened (`Git/Shell.swift:27-66`: stdin nulled, `GIT_TERMINAL_PROMPT=0`, 5s timeout). Recording and server off by default. `deleteAllData` reads `sqlite_master` rather than a hand-kept list.
- **Settings → "What FlowTrace knows"** (`SettingsView.swift:631-715`) is genuinely good privacy UX, and its copy is already in the Journal voice ("off until you turn it on", "so notes land on the page, not the app").
- **Journal design language** (`DesignSystem/Journal.swift`): two typographic voices (observed sans, your words serif italic), role-named palette tokens, amber-means-one-thing discipline (`NowView.swift:144-146`), SurfaceSwitch in the page header. Now/Today/Quick Capture copy matches the README voice exactly ("Nothing running.", "why did you open this?", "Written down.", "That day is gone").
- **Resilience details**: `DatabaseUnavailableView` instead of a crash (`FlowTraceApp.swift:25-31,70-84`); closing the window hides rather than quits; Accessibility polled every 1.5s so no relaunch; hot-key clashes reported as text; `seed` writes to a scratch file by default; MIT license; `./Scripts/test.sh` → 136 passed.

Tests: two captures from different apps with no recorder → two noted rows; stale open span at start → closed at yesterday's time.
